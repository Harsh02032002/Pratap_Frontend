Image compression — real before/after measurement

Runs the actual shared utility (src/utils/imageCompression.js) in a real browser, because canvas.toBlob cannot run under Node. Pick representative images — ideally straight from a phone camera — and copy the table into the report.

Serve it, don't open it from disk (ES module import needs http):

npx vite --open /scripts/measure-image-compression.html
# or:  python3 -m http.server 8080   →   http://localhost:8080/scripts/measure-image-compression.html
